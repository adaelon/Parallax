# G07 Retrieval Contract v2

状态：S14 冻结；实现与测试必须使用下列常量，任何语义变化都提升契约版本并重建派生索引。

G07 不新增 ADR：向量模型与索引均为版本化、可重建且可替换的候选发现派生物，没有形成难以逆转的架构权衡。

## 固定本地向量模型

- 检索契约：`eam-retrieval-v2`。
- 模型：`eam-subword-hash-embedding-v1`，纯本地、无网络和模型下载，输出 256 维有符号 `i16` 向量。
- 特征：Unicode 小写后的字母数字 run、完整 run、带边界的 3～5 字符子词；非 ASCII run 额外发出单字、双字和三字特征。
- 映射：固定 FNV-1a 64-bit 特征哈希决定维度与正负号；维度饱和累加，空输入产生零向量并拒绝向量召回。
- 相似度：对持久化向量做精确余弦比较，量化为 `0..=10_000` basis points；最低接受分数为 2,500。

该模型只用于候选发现，不具有事实资格。它以共享子词覆盖措辞变化，不声称具备通用语言模型的语义理解；若真实资料基准无法达到召回门槛，提升模型版本并重建向量表，不改证据或账本。

## 索引、重排与邻域

- 引擎：SQLCipher schema v11 内的精确向量表；每行只绑定 `EvidenceBlockRef`、模型版本和定长向量，可由规范证据块完整重建。
- 向量初选：每次最多保留 64 个候选；同分按稳定候选引用升序。
- 长期记忆通道：S14 固定独立召回位与排序位；S16 写入长期记忆前，Vault 实现稳定返回空集，不把普通账本伪装成长期记忆。
- 重排：按命中通道数、全文命中数、向量分数、稳定候选引用依次排序；显式时间范围继续作为全文、向量、关系与长期记忆的交集门禁。
- 邻域：每个种子最多扩展同一提取修订前后各 1 个结构块、7 天内同来源时间邻居共 4 个、1 跳关系邻居共 8 个；邻域不递归。
- 来源门禁：`current` 只允许 `PRESENT` 最新来源版本；`historical` 可保留旧版或 `SOURCE_REMOVED`，且必须显式携带当前性。

所有候选和邻域进入工作上下文前必须重新读取权威规范文本或带逐字来源的账本。索引片段、向量和值得分不得外发为事实或永久引用。

## Token budget 与冻结

- 合法预算：128～32,768 estimated tokens；默认 4,096。
- 估算：ASCII 字节按 `ceil(bytes / 4)`，非 ASCII Unicode scalar 按 1 token，另计固定来源元数据开销；同一实现同时用于选择与验收。
- 组窗：按重排顺序尝试种子，再在预算允许时加入相邻块；单块超预算时跳过，不截断权威原文，不用摘要替代。
- 冻结结果：包含检索/模型版本、预算、实际估算、窗口内每个永久块引用、逐字文本、来源 locator、归属、记录时间、适用时间和来源当前性。
- 重放：相同查询、权威输入、检索/模型版本与预算必须得到同序列及同一 SHA-256 replay digest；动态窗口自身不得成为永久引用。
- 数据出口：运行时只序列化本人 prompt、既有会话选择和这份冻结结果；repository、索引向量、未选证据和模型特征不得进入请求。

## 可重复基准与性能上限

- 质量夹具：`crates/retrieval/tests/fixtures/g07-retrieval-benchmark.tsv`；每个 query 的预期文档必须进入向量 Top-3，覆盖率必须为 3/3。
- 拒绝夹具：空语义输入、非法预算、超预算单块、低于阈值候选和非权威候选必须失败关闭或被跳过。
- 可重放：同一夹具连续构建两次，向量字节、排序、窗口和 replay digest 必须完全一致。
- 规模：固定 4,096 个 256 维向量的精确重排在 debug 测试中上限 5 秒；每个种子不得保留超过 14 个邻域候选，单次查询不得保留超过 64 个向量初选或 32,768 estimated tokens。

性能时限只用于固定合成夹具，不宣称真实硬件延迟保证；超过规模或真实资料延迟不可接受时，升级可重建索引引擎，不放宽权威回读和预算门禁。
