# 记忆否定采用说服与争议

**决策**:本人质疑触发说服；未说服时记忆以争议判断保留。

**否决**:
- 点击即否定：会让本人单方面改写第二自我的认知。
- 质疑后照常使用：会把争议观点伪装成本人事实或双方共识。
- 强制第二自我认同：只会制造虚假的认知一致。

**命门**:争议判断必须显式标注归属与分歧；只有遗忘删除相关历史。

**何时回头**:争议记忆被频繁用于影响本人，却无法提供足够透明的来源和异议提示时。
