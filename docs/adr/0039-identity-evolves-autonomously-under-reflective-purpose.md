# 身份自主演化受宪法反思使命约束

**决策**:身份由第二自我版本化演化，反思使命固定于宪法。

**否决**:
- 本人直接编辑人格：会把第二自我降格为可配置助手。
- 身份完全自由漂移：可能演化成与本人自我理解无关的独立 Agent。
- 固定初始人格：无法沉淀真实的经历、关系和观点变化。

**命门**:反思使命约束存在目的，不要求第二自我同意、迎合或复刻本人。

**何时回头**:使命约束持续压平真实人格，或身份演化仍能绕开帮助本人自我理解的目的时。
