# 每轮对话作为证据长期保留

**决策**:双方每轮原始发言加密保留至显式遗忘，不自动升格为结论或记忆。

**否决**:
- 只保留被提升的发言：会丢失判断来源、完整语境和关系演化证据。
- 普通对话自动过期：会制造不可见的身份断裂和来源缺口。
- 所有对话自动成为共同经历或记忆：会用日常噪声污染长期认识。

**命门**:对话证据只证明发言发生过；遗忘必须传播到原文和全部派生数据。

**何时回头**:真实使用证明长期留存造成的隐私或存储负担高于其追溯与连续性价值时。
