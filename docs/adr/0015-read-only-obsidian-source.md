# Obsidian 笔记库作为只读外部资料源

首版本人可以指定一个已有 Obsidian 笔记库，系统直接观察其中的本地文件并增量导入加密保险库，但不依赖 Obsidian 进程、不修改源文件，也不把该目录当作权威存储。这样可以保留原有笔记工作流，同时不让插件或同步冲突直接改写第二自我的内部状态。

## Considered Options

- 作为内部保险库：普通文件目录无法满足加密权威存储边界，否决。
- 双向同步：写回笔记会引入冲突、循环更新和意外修改本人资料，否决首版采用。
- 只读外部资料源：原笔记保持可移植，系统独立维护加密副本和派生认识，采纳。

## Consequences

适配器理解 Properties、标签、别名、内部链接、标题与块引用以及嵌入关系，但始终把它们视为不可信证据。Obsidian 配置目录和回收站不导入，插件不执行，外部链接不自动下载；源文件删除后的当前性与历史保留遵循 ADR-0016，具体语法边界遵循 [ADR-0024](0024-versioned-markdown-dialect.md)。
