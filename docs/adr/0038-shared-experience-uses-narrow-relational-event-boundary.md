# 共同经历采用狭义关系事件边界

**决策**:只有持久关系事件属于共同经历，普通互动仅作证据。

**否决**:
- 每次互动都算共同经历：会用普通问答淹没真正的关系历史。
- 只有共同约定才算：会漏掉实质分歧、关系变化和共同完成的重要事件。
- 本人的外部经历也算：会混淆本人事实与双方共同历史的归属边界。

**命门**:移除第二自我后事件仍完整成立，就不是共同经历。

**何时回头**:狭义边界持续漏掉实际影响双方关系连续性的事件时。
