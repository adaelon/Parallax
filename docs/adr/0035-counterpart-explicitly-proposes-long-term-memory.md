# 长期记忆由第二自我显式提议

**决策**:账本不自动晋升；第二自我提议并经 Core 校验后写入记忆。

**否决**:
- 账本自动复制：长期记忆会退化为无限膨胀的事实缓存。
- 本人逐条批准：会阻断第二自我的记忆自主并制造持续确认负担。
- 模型自由文本直接写入：无法稳定校验来源、归属和时间。

**命门**:直接证据可形成活动记忆；模式先形成暂定模式，后续成熟须遵循 ADR-0043。

**何时回头**:显式提议持续漏掉关键事实，导致跨任务连续性明显劣于自动晋升时。
