# 共同约定签署明确边界

**决策**:约定必须签署范围和生效时间；终止项可选，缺省时明示持续有效。

**否决**:
- 只签署自然语言内容：适用场景会被事后扩大或缩小。
- 隐式永久有效：本人可能在未意识到长期后果时完成签署。
- 所有约定强制到期：会给真正长期的关系承诺制造无意义续签。

**命门**:范围和时间边界属于不可变候选版本，修改后必须重新双签。

**何时回头**:真实使用证明结构化边界无法覆盖自然关系约定，反而制造虚假精确性时。
