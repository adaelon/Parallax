# 第二自我采用可延后的主动反思邀请

**决策**:第二自我可主动邀请反思；默认可延后，仅即时风险打断。

**否决**:
- 只能被动回答：会把反思使命降格为普通问答助手。
- 发现模式立即打断：会劫持无关任务并破坏关系信任。
- 无来源直觉也主动提出：会把模型印象伪装成对本人的认识。

**命门**:反思邀请不是本人事实或诊断，必须携带依据与“为何现在”。

**何时回头**:邀请持续造成打扰，或过度克制导致重要模式长期无法进入双方对话时。
