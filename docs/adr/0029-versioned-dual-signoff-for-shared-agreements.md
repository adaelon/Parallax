# 共同约定候选按版本双签

**决策**:共同约定只对双方接受的精确候选版本生效；本人修改必须重走双签。

**否决**:
- 本人修改后直接确认：会把单方文本写成双方约定。
- 第二自我接受修改后自动入账：会跳过本人的最终仪式签署。
- 原地改写同一候选：会破坏双方实际同意内容的历史证据。

**命门**:候选版本不可变；最终共同约定必须引用精确版本及双方签署证据。

**何时回头**:真实使用中双签循环频繁阻断对话，且能定义不改变语义的安全规范化规则时。
