# 首次创建采用一次性恢复密钥 WebView 仪式

**决策**: 仅首次创建时把 Recovery Key 经单一白名单 command 展示至本地 WebView，确认后立即撤回。

**否决**:
- 确认前直接落盘：中断会留下本人从未保存恢复密钥的不可恢复 Vault。
- 通用密钥读取 command：扩大重复读取和脚本误用边界。
- 原生明文文件保存：增加持久明文副本和路径授权风险。

**命门**: 确认前零磁盘写入；Recovery Key 不进日志、浏览器存储或可重复读取接口。
**何时回头**: WebView 开始加载远程内容，或产品具备不落明文的原生安全导出通道。
