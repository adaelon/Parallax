# 共同经历采用分类型仪式入账

**决策**:共同约定经仪式确认入账；实质分歧凭证据入账，弹窗不可否决。

**否决**:
- 弹窗只作通知：共同约定可能被一方单方面写入共同历史。
- 所有共同经历都需确认：一方可以否认已经发生的实质分歧。
- 完全不展示仪式：无法表达共同历史节点的重要性和关系重量。

**命门**:弹窗必须展示准确表述与双方证据；关闭分歧弹窗不改变其记录。

**何时回头**:仪式弹窗造成持续打扰，或真实对话无法稳定区分约定与实质分歧时。
