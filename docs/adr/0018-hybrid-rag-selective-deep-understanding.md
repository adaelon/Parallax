# RAG 常驻取证，深度理解按需构建

**决策**:多通道 RAG 常驻，深度理解仅按需构建。

**否决**:
- 仅向量 RAG：相似片段无法表达时间演化、归属和长期关系。
- 全库套用 `understand-book`：无限追加的人生记录会造成持续高成本和陈旧投影。
- 取消语义召回：未被深度处理的新证据会因措辞变化而漏检。

**命门**:向量结果和理解投影只能辅助路由，必须回到当前有效的权威证据。

**何时回头**:真实资料基准证明多通道召回仍无法达到可接受覆盖率，或深度构建成本低到可持续覆盖全库时。
