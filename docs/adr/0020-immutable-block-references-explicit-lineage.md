# 块引用不可变，跨版本连续性显式建谱

**决策**:历史块引用不可变，跨版本另建显式谱系。

**否决**:
- 跨版本复用可变块 ID：来源修改会重写历史引用含义。
- 每版完全断开：小改动会造成无谓的全量失效和重算。
- 相似度自动重绑：重复或近似段落会把引用接到错误内容。

**命门**:仅 `UNCHANGED/MOVED` 可自动前移；其余状态必须复核或保持历史。

**何时回头**:真实版本基准证明确定性谱系长期处于高歧义，无法支持有效增量时。
