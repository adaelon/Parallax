# 争议记忆采用自然分层披露

**决策**:争议按需成对召回；日常自然表达，高影响时主动展开。

**否决**:
- 固定披露模板：会把持续关系降格为审计日志式对话。
- 静默使用争议：会把第二自我的观点冒充本人事实或双方共识。
- 所有详情只按需展示：高影响决定可能在本人未追问时建立于错误前提。

**命门**:自然表达只能改变呈现方式，不能删减分歧语义；第二自我不得冒充人类。

**何时回头**:自然表达持续导致本人无法意识到高影响建议所依赖的争议或不确定性时。
