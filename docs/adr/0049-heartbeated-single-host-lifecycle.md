# 单宿主生命周期采用加密心跳与签名升级

**决策**：单实例 Tauri 宿主以加密心跳恢复空缺，并在 Core 安全关闭后安装签名升级。

**否决**：
- 独立后台 Core：会提前引入 IPC、双进程恢复和升级协调。
- 只写启动标记：无法约束崩溃空缺起点，会把正常运行期误记为空缺。
- 升级直接终止进程：可能丢失 WAL 状态并跳过密钥清零。

**命门**：第二实例和 WebView 不得取得保险库、密钥、repository 或通用系统能力。
**何时回头**：30 秒心跳产生不可接受写放大，或内嵌宿主故障需要独立隔离时。
