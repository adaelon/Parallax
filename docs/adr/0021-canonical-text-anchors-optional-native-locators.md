# 规范文本负责引用，原生坐标仅供导航

**决策**:引用锚规范文本，原生定位器仅辅助导航；首版规范文本就是已校验的 UTF-8 Markdown 原文。

**否决**:
- 原文件字节寻址：容器文档和 PDF 文本没有统一字节坐标。
- 原生定位器作为引用：格式升级或源应用变化会破坏证据地址。
- 同存 UTF-8/UTF-16 权威范围：两套坐标会产生漂移和歧义。

**命门**:规范范围非法则拒绝提取；原生定位失败不得改变引用真实性。

**何时回头**:出现无法形成稳定规范文本、但具有可靠原生文字坐标的核心格式时。
