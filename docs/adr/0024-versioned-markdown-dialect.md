# 首版采用版本化 Markdown 方言

**决策**:首版采用 CommonMark/GFM 与固定 Obsidian 子集。

**否决**:
- 完整复现 Obsidian：行为受应用版本、设置和插件影响，无法稳定验收。
- 只支持 CommonMark：会丢失既有笔记库最重要的属性和关系。
- 未知语法即拒绝整篇：会让可读原文因局部扩展而不可用。

**命门**:未知语法保留原文但不获专用语义；结构行为变化必须提升方言版本。

**何时回头**:真实笔记中某项未支持语法持续影响检索、引用或关系理解时。
