# 任一方可向未来退出共同约定

**决策**:任一方可单方面终止未来约束；原约定及履行历史保持不变。

**否决**:
- 退出也需双方同意：会把关系约束变成一方无法离开的永久承诺。
- 退出时删除原约定：会破坏共同历史和后续行为的解释依据。
- 原地改写约定内容：会绕过候选版本和双方双签。

**命门**:退出必须记录行为方和生效时间，只改变当前关系约束投影。

**何时回头**:单方退出被频繁滥用，导致共同约定无法形成任何稳定预期时。
