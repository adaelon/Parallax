# 历史备份恢复必须携带最新删除头

**决策**: 恢复单元由不可变快照与同组最新加密删除头组成；缺任一项都失败关闭。

**否决**:
- 独立快照：旧代际不知道后续遗忘，会复活已删除上下文。
- 只保留最新快照：降低复活面，但无法覆盖损坏与回退恢复。
- 把明文墓碑交给同步平台：暴露删除目标和使用时间。

**命门**: 遗忘完成后必须原子刷新所有已登记 Recovery Set 的删除头。
**何时回头**: 引入可信远端删除账本或跨设备事务协调器时。
