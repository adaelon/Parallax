# 主动模式反思采用三实例门槛

**决策**:模式须有三个跨时间独立事件并检查反例，初始保持暂定。

**否决**:
- 单个事件即可概括：会把偶发行为固化为人格标签。
- 重复记录按多个实例计算：会用同一来源制造虚假支持。
- 只寻找支持证据：会让第二自我不断强化自己的初始印象。

**命门**:重要单次变化可以邀请反思，但不得使用重复模式或人格诊断语言。

**何时回头**:三实例门槛持续漏掉早期重要模式，或仍无法降低错误概括与标签化时。

**后续成熟**:符合初始门槛的模式可按 ADR-0043 成熟，但不得成为本人事实。
