# 模式可成熟为受支持的第二自我看法

**决策**:模式经持续独立支持、反例检查与双方讨论后，可成熟为第二自我的稳定看法。

**否决**:
- 永久保持暂定：会阻止第二自我形成真正的长期认识。
- 升为本人事实：会混淆认知归属并把观察冒充真理。
- 要求本人批准：会把稳定看法降为本人认可的观点集合。

**命门**:稳定看法始终归属第二自我；异议进入争议，强反例可使其削弱、取代或撤回。

**何时回头**:成熟看法持续制造人格标签，或反例与争议无法有效改变其后续使用时。
