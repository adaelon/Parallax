# 保险库采用加密关系库与加密对象库

权威结构化状态存入 SQLCipher `self.db`，导入原件存入逐对象认证加密的不可变 `objects/`；两者由随机 Vault Key 派生独立子密钥。该混合方案兼顾事务查询、去重、增量备份和大文件管理，同时避免文件系统暴露个人元数据。

## Considered Options

- 全部存为数据库 BLOB：事务边界简单，但大文件会放大数据库、WAL 和增量备份成本。
- 明文文件加加密数据库：实现简单，但原件、文件名和目录结构会越过加密边界。
- SQLCipher 加加密对象库：结构化数据与原件采用各自合适的持久化方式，采纳。

## Consequences

Rust Core 是唯一持有解锁后 Vault Key 的组件；对象使用带密钥的内容标识，个人元数据只进入加密数据库。本机 DPAPI 副本与独立 Recovery Key 分别封装 Vault Key。遗忘会清理活动存储和派生数据，但首版不承诺 SSD 或历史备份的法证级物理擦除。
