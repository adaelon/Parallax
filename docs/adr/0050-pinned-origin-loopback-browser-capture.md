# 浏览器采集采用固定来源环回会话通道

**决策**：MV3 扩展以固定来源访问仅环回 HTTP，握手后用随机宿主会话令牌提交有界事件。

**否决**：
- WebView command：会把扩展写入口错误并入界面权限面。
- Native Messaging：首版需额外宿主注册、代理进程与升级协调。
- 无认证 localhost：其他来源可直接伪造浏览证据。

**命门**：只绑定 `127.0.0.1`，严格校验扩展来源，令牌不落盘且不进日志。
**何时回头**：需要抵抗已攻陷的当前登录会话，或环回来源校验无法跨目标 Chromium 稳定工作时。
