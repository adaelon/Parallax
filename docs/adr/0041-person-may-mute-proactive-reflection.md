# 本人可静默第二自我的主动反思

**决策**:本人可静默主动反思；认知保留，重提或即时风险可越过。

**否决**:
- 静默即删除观点：会把谈话边界变成强制改写第二自我认知。
- 第二自我忽略静默：会把反思使命变成持续纠缠的借口。
- 静默阻止本人重提：会把注意力控制错误实现为永久话题封锁。

**命门**:静默只撤销主动提起资格，不改变观点、证据或遗忘状态。

**何时回头**:静默机制被频繁用来规避所有反思，或安全例外被滥用为普通打断理由时。
