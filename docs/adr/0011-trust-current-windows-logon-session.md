# 首版信任当前 Windows 登录会话

首版必须防御丢失的存储介质、其他非管理员账户、远程连接、外部模型与工具越权以及恶意内容，但假定当前 Windows 登录会话和操作系统未被攻陷。该边界让后台自动解锁和持续采集可用，同时避免声称无法兑现的主机入侵防护。

## Considered Options

- 抵抗同一登录会话中的恶意进程：需要更强应用身份、交互解锁和密钥代理，并显著限制无感后台运行，推迟。
- 抵抗本机管理员或内核攻击：保险库解锁并工作时无法作出可靠保证，不纳入首版承诺。
- 信任当前登录会话并实施纵深加固：与 Windows 首版和自动记录目标相容，采纳。

## Consequences

本地文件和 IPC 仍必须使用显式最小权限、拒绝远程访问、命令白名单和无正文日志；“不在威胁模型内”不等于使用宽松默认值。产品不得宣称能保护已被控制的当前账户、管理员或设备解锁时的物理访问。
