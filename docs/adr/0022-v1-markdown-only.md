# 首版只理解 UTF-8 Markdown

**决策**:首版只有 UTF-8 `.md` 文件可被提取、检索并用于记忆。

**否决**:
- 首批支持多种文档格式：需要维护格式适配、转换语义和更大的测试矩阵。
- 通用文档中间表示：对 Markdown 单格式没有足够收益。
- 只保存解析后的纯文本：会丢失原始证据、结构和精确引用位置。

**命门**:Markdown 原文就是规范文本；解析只叠加结构与原文范围，不生成第二份权威正文。

**何时回头**:Markdown 闭环稳定后，真实资料需求证明某一种新增格式的收益足以承担独立适配与验收成本时。
