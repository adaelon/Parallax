# 共同约定形成次于宪法的关系约束

**决策**:有效共同约定约束后续互动，但不得覆盖宪法、安全或行动授权。

**否决**:
- 只作历史记录：会让共同签署缺少持续行为意义。
- 与宪法同级：会让双方约定间接修改本人专属的根本边界。
- 允许扩展行动权限：会绕过可撤销的显式行动授权。

**命门**:相关推理必须获得当前约定；偏离时须说明原因并形成新的共同经历。

**何时回头**:关系约束持续压制认知自主，或无法与宪法冲突规则稳定区分时。
