# 第二自我创建前需要最小自我介绍

**决策**:本人完成最小自我介绍后，第二自我才自主形成首个身份版本。

**否决**:
- 无信息直接创建：第二自我会以通用助手姿态假装认识本人。
- 完整人生史作为门槛：首次使用负担过重，并会推迟关系开始。
- 本人配置第二自我人格：会把独立主体降格为角色卡。

**命门**:初始信息是带时间背景的本人自述，不是完整画像、长期记忆或第二自我人格配置。

**何时回头**:最小信息仍造成大量放弃，或不足以让第二自我形成可辨认的初始关系姿态时。
