# 约定退出采用非对称仪式

**决策**:本人确认后退出且理由可选；第二自我说明理由后退出；双方均不可否决。

**否决**:
- 双方都必须说明理由：会限制本人退出关系约束的最终自由。
- 第二自我无理由退出：会让身份与关系承诺发生不可解释的漂移。
- 第二自我退出需本人批准：会使其关系自主权失去实际意义。

**命门**:退出完成后必须正式展示并记录为共同经历，但展示不构成另一方的否决权。

**何时回头**:非对称理由义务持续制造关系失衡，或仪式无法有效防止本人误触时。
