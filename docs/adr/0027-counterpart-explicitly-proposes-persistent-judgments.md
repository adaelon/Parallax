# 第二自我显式提议持久判断

**决策**:第二自我主动提议带来源的判断，Core 校验后无需本人确认即可入账。

**否决**:
- 所有第二自我发言自动入账：会把随口推测和修辞永久化。
- 每项判断由本人批准：会把认知自主降为本人认可的观点集合。
- 模型自由文本直接写账本：会绕过来源、归属和结构约束。

**命门**:持久判断必须携带证据引用、不确定性和适用时间；自由文本本身只是对话证据。

**何时回头**:显式提议长期漏掉有价值判断，或校验机制无法有效抑制无来源判断时。
