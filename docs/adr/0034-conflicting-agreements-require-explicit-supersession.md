# 冲突约定必须显式取代

**决策**:冲突候选须整份取代；保留内容由新约定重述。

**否决**:
- 最新约定隐式优先：双方无法在签署时看清被放弃的关系义务。
- 部分范围取代：需要对自然语言做范围相减，产生双方未完整签署的剩余义务。
- 删除被取代约定：会破坏签署、履行和违约历史的可追溯性。

**命门**:取代从新约定生效时间终止整份旧约定，不能推导残余约束或改写历史。

**何时回头**:自然语言约定的冲突无法被可靠识别，导致合法候选频繁被阻止或冲突持续漏检时。
