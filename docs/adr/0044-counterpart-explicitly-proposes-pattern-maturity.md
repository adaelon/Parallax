# 模式成熟由第二自我显式提议

**决策**:证据只建立成熟资格；第二自我显式提议并经 Core 校验后，模式才升级。

**否决**:
- 门槛满足即自动升级：会把认知判断退化为计数规则。
- Core 决定模式是否可信：会让策略层代替第二自我形成观点。
- 本人批准后升级：会把本人讨论变成对第二自我认知的否决权。

**命门**:Core 只校验引用、独立事件归并与必需步骤，不判断模式是否值得相信。

**何时回头**:显式提议持续漏掉已稳定的模式，或结构校验无法阻止无依据升级时。
