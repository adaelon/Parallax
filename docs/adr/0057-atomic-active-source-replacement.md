# 活动资料源原子替换

**决策**：系统只持续观察一个活动资料源；新目录首次对账成功后才原子取代旧目录。

**否决**：
- 多目录同时活动：扩大首版调度、状态解释和资源预算边界。
- 选择后立即切换：首次扫描失败会让可用旧资料源无故退出当前检索。
- 替换时删除旧证据：目录配置变更不构成遗忘授权。

**命门**：旧资料源停用后保留历史证据，但不得继续进入默认当前检索或后台监控。
**何时回头**：产品明确需要多个目录同时参与当前认识时。
