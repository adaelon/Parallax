# 首批可理解文件格式采用平衡文本资料集

首版解析 `.txt`、`.md`、带文字层的 `.pdf`、`.docx`、`.html`、`.epub`、`.json` 和 `.csv`。这组格式覆盖笔记、常用文档、网页、电子书和结构化数据导出，同时把 OCR、媒体转录及复杂 Office 语义留出首个闭环。

## Considered Options

- 最小文本集：只支持纯文本、Markdown 和 PDF，交付快但大量常见资料仍不可理解。
- 平衡文本资料集：覆盖主要文字载体而不引入 OCR 和媒体处理，采纳。
- 广泛媒体集：同时支持图片、表格、幻灯片及音视频，解析成本、安全面和验收规模过大。

## Consequences

扫描 PDF、图片、`.pptx`、`.xlsx`、音视频、MHTML 和旧版 Office 文件首版只按 ADR-0013 加密归档。具体解析库、进程隔离和资源上限另行决策；格式识别不得只信任扩展名。
