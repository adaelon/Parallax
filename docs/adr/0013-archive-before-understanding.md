# 上下文收件箱先归档后理解

稳定且符合导入边界的普通文件先以加密原件写入保险库并记录为 `ARCHIVED`，随后才尝试识别和解析。暂不支持、需要密码、需要 OCR 或解析失败的文件进入带原因的 `ARCHIVED_UNPARSED`；在成功提取前，它们不进入检索、记忆或 Agent 工作上下文。

## Considered Options

- 只接收可解析文件：存储精简，但新增解析能力后仍需本人保留并重新投递原件。
- 解析成功后才归档：解析失败会让保险库缺失本人已经投递的上下文。
- 先归档后理解：保留未来可恢复性，同时不把未知内容伪装成可用认识，采纳。

## Consequences

重解析任务只读取已归档密文原件，并在解析能力新增或升级后增量推进状态。文件名和失败原因可供本人在 Personal Library 管理，但 Agent 不得仅凭文件名推断内容。收件箱不跟随重解析点或符号链接，也不读取设备文件；超出自动导入上限的普通文件等待本人确认。
