# 结构块稳定寻址，检索窗口动态派生

**决策**:证据按结构块寻址，检索窗口按需派生。

**否决**:
- 仅存扁平全文：来源结构丢失，无法稳定局部引用和失效。
- 固定 token 切片：模型预算会反向定义权威数据边界。
- 模型自由分块：同一来源无法确定性重放和增量比较。

**命门**:块身份由 Core 绑定提取修订，来源或契约变化不得静默重绑旧引用。

**何时回头**:真实格式基准证明结构块无法稳定复现，或结构保留显著降低检索质量时。
